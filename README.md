# 🎯 Probability Switching Test - Monty Hall Simulation
This project simulates the classic Monty Hall Problem, a probability puzzle that demonstrates the surprising advantage of switching choices in a three-door game show scenario.

Using Python and Tkinter, this program lets users run multiple simulations to compare the success rate of two strategies:

Staying with the original door choice

Switching to the remaining unopened door

📊 What It Demonstrates
When players switch, they win roughly 66.7% of the time.

When players stay, they win roughly 33.3% of the time.

This simulation confirms the counterintuitive probability through repeated trials.

🧠 Key Features
Interactive GUI built with Tkinter

Real-time display of win counts for both strategies

User-defined number of simulations

Clean and beginner-friendly codebase

🚀 How to Use
Run the Python script.

Enter the number of simulations in the input field.

Press Enter to view the results.
